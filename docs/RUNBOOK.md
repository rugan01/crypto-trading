# Runbook

## Requirements

- Python 3.10 or later recommended.
- Internet access to `https://api.india.delta.exchange`.
- `requests` from `requirements.txt`.
- No API key for public products and historical candles.

## Installation

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
python -m unittest -q
```

## Research commands

```bash
# Product coverage audit
python delta_0dte.py audit --days 30

# Relative window
python delta_0dte.py backtest \
  --days 90 --lots 200 --slippage-bps 50 \
  --output results/research_90d_50bps

# Exact window
python delta_0dte.py backtest \
  --start-date 2026-01-01 --end-date 2026-07-10 \
  --lots 200 --slippage-bps 50 \
  --output results/research_2026_jan01_jul10_50bps
```

Run cost sensitivities by changing `--slippage-bps` to `0` and `100` and using
separate output directories. Cached API data makes repeat runs much faster.

## Frozen validation commands

These commands reproduce the historical experiment. They no longer represent
unseen tests because the results are already known.

```bash
python validate_2025.py --phase validation --slippage-bps 50 \
  --output results/validation_2025_sep_dec_frozen

python validate_2025.py --phase final_holdout --slippage-bps 50 \
  --output results/final_holdout_2025_jan_aug
```

## Premium analysis

`analyze_btc_premium.py` depends on the three historical trade ledgers and cached
BTC spot candles generated by the preceding runs.

```bash
python analyze_btc_premium.py
```

Outputs:

- `observations.csv`: one row per expiry;
- `group_metrics.csv`: premium/balance bucket statistics;
- `summary.json`: frozen distribution/correlation summary;
- `REPORT.md`: interpretation and anti-overfitting boundary.

## Backtest outputs

- `trades.csv`: auditable entry/exit ledger.
- `summary.csv`: grouped performance metrics.
- `data_audit.csv`: requested versus completed expiries.
- `skips.json`: explicit missing-data counts.
- Validation runs additionally emit `diagnostics.csv`,
  `diagnostic_groups.csv`, and `manifest.json`.

## Credentials

Historical commands use public endpoints. For any private read-only extension:

```bash
cp .env.example .env
# populate locally; never commit .env
```

Delta requires the current machine IP in the API-key whitelist. Do not print
headers, keys, secrets, signatures, balances, or account identifiers.

## Troubleshooting

- `HTTP 429`: the client uses reset headers/backoff; let the cached run resume.
- Old contract absent from product list: direct symbol resolution is automatic.
- Empty option candles: verify symbol, expiry, resolution, and Delta retention.
- `ip_not_whitelisted_for_api_key`: update the key's IP whitelist; do not bypass.
- Testnet TLS/network failure: historical research can use public production
  market data, but never use that as permission for live order testing.
- Premium analysis says missing spot: run the relevant backtest first to populate
  the raw cache.
